# gravia-mlops

CI/CD et déploiement de [GRAVIA](https://github.com/VigiRoute/gravia) — IaC (Terraform), manifests
Kubernetes, workflows de déploiement. `gravia` **construit** la solution, `gravia-mlops` la
**déploie** (cf. [gravia/CLAUDE.md](https://github.com/VigiRoute/gravia/blob/main/CLAUDE.md)).

Voir [CLAUDE.md](CLAUDE.md) pour le détail des choix techniques (pourquoi `kind`, comment lancer
la démo locale, conventions de ce dépôt).
